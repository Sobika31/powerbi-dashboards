# powerbi-dashboards
This repository showcases a collection of interactive **Power BI dashboards** developed to transform raw data into meaningful business insights through data analysis and visualization. The project includes five dashboards: **Amazon Sales Analysis, Adidas Sales Analysis, Movie Details Analysis, Pizza Order Analysis, and UK Road Accident Analysis.**

Each dashboard is designed with an attractive layout, interactive slicers, KPI cards, charts, and visual reports to explore key performance indicators and identify important trends and patterns.

### 📊 Projects Included
1. **Amazon Sales Dashboard:** Analyzes sales, profit, discounts, product categories, sub-categories, and city-wise performance.
2. **Adidas Sales Dashboard:** Provides insights into total sales, units sold, operating profit, product categories, regions, cities, and sales methods.
3. **Movie Details Dashboard:** Explores movie ratings, popularity, vote counts, genres, release years, and original languages.
4. **Pizza Order Details Dashboard:** Analyzes pizza sales, quantity, revenue, tax amounts, product categories, pizza sizes, and order performance.
5. **UK Road Accidents Dashboard:** Examines accident casualties, vehicle types, road types, districts, speed limits, and geographical accident patterns.

### 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query for Data Cleaning and Transformation
- DAX (Data Analysis Expressions)
- Data Modeling
- Interactive Slicers and Filters
- KPI Cards
- Charts and Graphs
- Data Visualization

### 🎯 Project Objectives
- Convert raw datasets into interactive dashboards.
- Track important business KPIs and performance metrics.
- Identify trends and patterns through visual analysis.
- Compare performance across different categories and regions.
- Support data-driven decision-making.
